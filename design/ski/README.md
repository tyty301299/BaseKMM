# SKI

SKI is the camera assistant for conversation, personal styling and practical skills.
The S ribbon evokes fabric and a continuous learning path; the focus corners stand
for understanding what the camera sees. The yellow (#FFD23F) and near-black
(#0B0B0F) match the product interface.

`ski-logo-master.png` is the original generated logo, made with the built-in image
generation tool. `prompt.txt` records the generation specification. App icons are
resized exports; iOS applies its own corner mask. The same logo is installed in the
web, Android and iOS source assets. The Android themed icon uses a simple vector
adaptation of the ribbon and focus corners.

Only the product identity changes. Existing bundle IDs, API paths, storage keys,
access headers and deployment names remain compatible with installed apps and data.
